  • 来源标记 —— 每个值都标了是 whois 查到的还是回退兜底的

字段说明

响应里带 *_source 标记，说明这个值是 whois 查到的，还是没查到时的兜底值 —— 这在拿它做判断时很重要。

字段含义

接口

同一个路径按 Accept 协商：浏览器拿到页面，其他客户端拿到 JSON。想强制要 JSON 就加 ?format=json。

单个查询（省略 q 就查调用方自己的 IP）
# 指定地址
curl '$ORIGIN/?q=32.5.140.2'

# 查自己
curl '$ORIGIN/'
批量查询，最多 100 个，返回等长数组
curl -X POST -H 'Content-Type: application/json' \
     -d '{"ips":["8.8.8.8","1.1.1.1"]}' \
     '$ORIGIN/'
健康检查（含缓存条目数）
curl '$ORIGIN/healthz'
# {"ok":true,"company_netblocks":128,"asn_orgs":64}

数据来源

全部是公开数据，可自行下载重建，不依赖任何商业授权。

数据来源更新
地理位置ipapi-is/ipapi 免费 geolocation 库仓库不定期
IP → ASNiptoasn.com（源自 RouteViews）每小时
company_name各 RIR 的 RDAP ip/ 对象按需查询 + 本地缓存
asn_org各 RIR 的 RDAP autnum/ 对象按需查询 + 本地缓存

未实现 is_datacenter / is_vpn / is_proxy / is_abuser / is_tor —— 这些依赖 ipapi.is 的商业库，没有可靠的免费替代。默认它们不出现在响应里，避免"查不到"被误读成"确定不是"。

自托管部署，查询不出网（RDAP 首次回源除外）。 —
